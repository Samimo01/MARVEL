# Palette de couleurs du site

Couleurs extraites des fichiers : `index`, `inscription`, `inscription2`, `mon-espace`, `campagnes`, `demander-aide`, `don`, `evenements`.

## Couleurs principales (identité)

| Rôle | Variable CSS | Couleur | Remarque |
|---|---|---|---|
| Encre / violet profond | `--ink`, `--deep` | `#1B0F3B` | La plus utilisée du site (textes, fonds sombres, boutons) |
| Accent corail | `--accent` | `#FF6B4A` | Boutons, appels à l'action |
| Violet | `--violet` | `#A478FA` | Accent secondaire |
| Champagne | `--champagne` | `#F7E7B6` | Touches dorées, focus, badges |
| Fond clair | `--bg` | `#FAF7FC` | Fond des pages en mode clair |
| Surface | `--surface` | `#FFFFFF` | Cartes, formulaires |

## Transparences (rgba)

Le site utilise beaucoup de transparences des couleurs principales, pour les bordures, ombres et fonds légers :

- Blanc : `rgba(255, 255, 255, .03 à .95)`
- Encre : `rgba(27, 15, 59, .04 à .84)`
- Corail : `rgba(255, 107, 74, .05 à .55)`
- Violet : `rgba(164, 120, 250, .03 à .85)`
- Champagne : `rgba(247, 231, 182, .03 à .95)`
- Noir : `rgba(0, 0, 0, .1 à .5)`
